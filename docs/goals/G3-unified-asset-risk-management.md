# G3：统一资产与组合风险管理

## 目标身份

- 优先级：P0，项目第一优先级
- 状态：ACTIVE
- 执行方式：Loop Engineering
- 状态文件：`G3_LOOP_STATE.md`
- 人工边界：真实资金阈值启用、减仓和 SELL 操作必须经过人工确认

## 业务目标

建立可信的账户总资产账本、组合暴露视图和真实下单硬风控，使单次归零、重复下注、相关仓位和长期占资不再轻易抵消多次盈利。

总资产统一口径为：

`可用余额 + 钱包当前持仓价值 + 已结算待赎回价值`

报价缺失或数据源失败必须记为“估值未知”，不得按零价值静默计算。

## 完成条件

只有同时满足以下条件，G3 才能标记完成：

1. 每个启用账户都有连续、可追溯的北京时间每日零点资产快照。
2. 总资产可以拆分核对余额、持仓价值、待赎回价值和未知估值。
3. 页面可观察账户、Leader、领域、事件四层资金暴露。
4. BUY 下单前执行组合风险检查，Bridge 不能绕过；SELL 不被普通 BUY 风控阻断。
5. 每日亏损、订单数、单市场仓位、Leader/领域集中度和现金储备形成可审计硬限制。
6. 系统能识别重复、对冲、伪对冲、相关和长期占资仓位。
7. 页面提供人工暂停 BUY、减仓预览和逐笔确认入口。
8. 历史回放通过，并完成至少 3 天 Shadow 观察；正式阈值由人工确认后逐项启用。
9. 后端测试、前端构建和 Bridge 相关测试通过，运行健康检查正常。

## 不可突破的安全边界

- 不允许模型或 Bridge 绕过后端硬风控。
- 不自动新增 Leader，不自动放宽阈值，不自动加仓。
- 普通减仓建议只生成方案，不直接执行。
- SELL 优先退出，但仍必须校验真实持仓和订单幂等。
- 数据不可信时禁止新增 BUY，允许进入人工复核或安全退出路径。
- 所有风险决策必须保存输入快照、命中规则、阈值和结果。

## 阶段计划

### Phase 1：资产账本与数据可信度

- 审计现有余额、持仓、待赎回和每日快照数据链路。
- 补齐盘中风险快照与零点快照的口径区分。
- 把缺失报价、接口失败和真实归零分开建模。
- 建立资产分项核对、补录和异常可观测能力。

验收：同一账户重复计算稳定；任何总资产数字均可追溯；异常数据不被按零处理。

### Phase 2：四层组合暴露

- 聚合账户、Leader、领域和事件暴露。
- 展示成本、当前价值、盈亏、资产占比、占资时长和数据可信度。
- 支持从风险总览下钻到持仓及跟单配置。

验收：持仓无静默遗漏，暴露合计能与资产账本对账，未知归属单独展示。

### Phase 3：组合级风险引擎

- 定义账户级和全局级风险策略及版本。
- 首版覆盖现金储备、单笔、单事件、单 Leader、单领域、每日亏损和订单数。
- 加入并发预占，避免并发订单共同突破阈值。
- 先运行 Shadow，仅记录允许或拒绝建议。

验收：每个决策可重放；前端和 Bridge 均不能绕过；SELL 保持优先。

### Phase 4：重复、对冲与相关仓位

- 优先用 condition/event、标准化实体、方向和时间窗口进行确定性关联。
- 区分重复、真对冲、伪对冲、相关和未知关系。
- Crypto、金融、政治分别配置相关性规则，不使用一个通用文本模型硬套。

验收：典型历史仓位分类正确，不自动把相反 outcome 当作完全抵消。

### Phase 5：人工风险处置

- 提供暂停相关 BUY、减仓预览、逐笔确认和失败重试入口。
- 展示处置前后资产、现金和集中度变化。
- 对无法卖出和长期占资仓位建立人工队列。

验收：所有真实处置均有确认和审计记录，暂停 BUY 不影响安全退出。

### Phase 6：回放、Shadow 与启用

- 使用 SUCCESS、FAILED 风控、未结算和结算记录进行历史回放。
- 对比收益、最大回撤、归零损失、资金利用率、过滤率和 SELL 完成率。
- Shadow 至少运行 3 天，再由人工逐项启用硬限制。

验收：没有不可解释的决策差异；规则不会把系统过滤到无法正常交易；具备紧急关闭和回滚能力。

## Loop 执行协议

每轮只推进一个可验证增量：

1. Discover：读取当前状态、真实数据、代码和测试，选择最高价值缺口。
2. Plan：定义本轮范围、风险、测试和明确完成条件。
3. Act：进行最小改动，不顺带重构其他目标。
4. Check：运行自动测试、差异审查和必要的运行时核对。
5. Record：更新 `G3_LOOP_STATE.md`，记录证据、失败和下一轮。
6. Decide：满足本阶段验收则进入下一阶段；否则继续修正或明确升级人工决策。

同一阻塞连续出现三轮且没有安全替代路径时，停止自动推进并请求人工决策。
