# G3 Phase 2：组合暴露基线

## 口径

- 账户总资产：余额 + 开放持仓价值 + 待赎回价值。
- Leader 暴露：按 Bridge 成功成交账本中的 Leader 净数量分摊当前持仓价值。
- 领域暴露：市场元数据优先，标题规则只作为回退。
- 事件暴露：使用 `eventSlug`；缺失时进入 `UNKNOWN`。
- 任意无法解释的价值必须进入 `UNKNOWN`，不得从维度合计中消失。
